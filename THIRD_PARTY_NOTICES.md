# Ассеты и зависимости

Этот этап содержит исходники приложения, а не готовый бинарный дистрибутив. Перед коммерческой поставкой необходимо отдельно проверить состав собранного onedir-каталога и приложить все требуемые лицензии.

## Muli и Mulish

Muli распространяется по SIL Open Font License 1.1, допускающей включение в приложение с сохранением уведомлений; отдельная продажа самого шрифта не разрешена ([лицензия Muli](https://raw.githubusercontent.com/googlefonts/MuliFont/580b05e1f2ad319cd98a8de03fd2da7b36677954/OFL.txt)).

В архив включены оригинальные `Muli-Regular.ttf`, `Muli-SemiBold.ttf` и полный текст `Muli-OFL.txt`. Muli применяется основным шрифтом; загруженные файлы Muli не содержат русских букв, что проверено по индексам глифов.

Кириллица дополнена Mulish, для которого Google Fonts указывает поддержку cyrillic/cyrillic-ext ([метаданные Mulish](https://raw.githubusercontent.com/google/fonts/main/ofl/mulish/METADATA.pb)). Его лицензия также SIL OFL 1.1, полный текст включён в `Mulish-OFL.txt` ([лицензия Mulish](https://raw.githubusercontent.com/google/fonts/main/ofl/mulish/OFL.txt)).

Из официального variable TTF Mulish подготовлены статические начертания 400 и 600: `Mulish-Regular.ttf` и `Mulish-SemiBold.ttf`. Генератор `tools/prepare_fonts.py` использует FontTools с обновлением таблицы имён; контуры не редактировались вручную, но файлы являются статическими производными, а не побайтовыми копиями variable-font.

Разделение Muli/Mulish явно задано в QFont и QSS. Проверяется фактический шрифт кириллических glyph runs, чтобы результат не зависел от случайного шрифта в Windows.

## Intel PresentMon 2.6.0

В клиентский пакет включён официальный консольный `PresentMon.exe` из релиза Intel/GameTechDev `v2.6.0`: https://github.com/GameTechDev/PresentMon/releases/tag/v2.6.0 . Он используется только по явному запуску игрового замера и получает сведения о представленных кадрах через Windows ETW.

SHA-256 официального бинарника: `b2a706bc6ad475749e3b7e3409263aa1e6906d45bdcf993f6dbc0f660188f1af`. Программа проверяет размер и хеш перед каждым запуском. Лицензия MIT и сторонние уведомления сохранены в `app/assets/tools/PresentMon-LICENSE.txt` и `PresentMon-THIRD_PARTY.txt`. Генератор `tools/prepare_presentmon.py` закрепляет версию, размер и хеш для воспроизводимого обновления.

## Инструменты разработчика

Pillow используется только для подготовки изображений, pytest только для тестов. Они перечислены в `requirements-dev.txt` и не требуются для обычного запуска интерфейса.

## Зависимости этапа 4

Клиент использует httpx и qrcode. FastAPI/Uvicorn используются только API. Реализация бота и зависимость aiogram удалены из проекта. API, runtime и секреты не входят в клиентскую сборку.
