# Каталог 1.0.0 · 23 настройки

Полный машинный список операций, описаний, рисков и источников находится в `app/core/catalog.py`. Удалённый сервер не может добавлять команды или менять пути.

## Игра · 7

- Отключение записи Game DVR.
- Игровой режим Windows.
- Полноэкранная оптимизация выбранного `cs2.exe`.
- Высокопроизводительный GPU для выбранного `cs2.exe`.
- `fps_max 400`, `fps_max 0` и `cl_showfps 1` в управляемом блоке `autoexec.cfg`.

## Система · 8

- Прозрачность и часть визуальных эффектов Windows.
- Фоновые приложения Microsoft Store.
- Задержка пользовательской автозагрузки.
- Быстрый запуск Windows.
- Эксперимент: системные запросы точного таймера только Windows 11, без обещания постоянных 0,5 мс.
- Эксперимент: HAGS при поддержке Windows и драйвера.
- Эксперимент: GPU Priority, Priority и SFIO Priority профиля MMCSS Games; Scheduling Category не повышается.

## Ввод · 2

- Ускорение указателя Windows.
- Залипание клавиш и его активация пятикратным Shift.

## Питание · 1

- Существующая стандартная схема «Высокая производительность»; новые схемы не создаются.

## Приватность · 5

- Рекламный ID и советы Windows.
- Минимальный доступный уровень диагностики; полное отключение телеметрии не обещается.
- Автозапуск DiagTrack без удаления службы.
- Раздача обновлений другим ПК без отключения Центра обновления.

## Пресеты

- FREE: Game DVR, прозрачность, ускорение мыши.
- Сбалансированный PRO: базовые игровые и системные параметры.
- Производительность PRO: расширенный набор без экспериментальных таймера, HAGS и MMCSS.
- Приватность PRO: рекламный ID, советы и раздача обновлений.
- CS2 PRO: Game DVR, игровой режим, лимит 400 FPS и счётчик.
- Свой набор PRO: любые отмеченные пользователем пункты, включая явно отмеченные эксперименты.

Для HKCU/HKLM сохраняются исходные значения и факт отсутствия. Разрешённые отсутствующие разделы создаются только для фиксированных путей каталога. Для `autoexec.cfg` сохраняется исходный текст; применение меняет только команды с совпадающими ключами внутри блока Shatli FLUX. Чужие изменения при откате не перезаписываются.
