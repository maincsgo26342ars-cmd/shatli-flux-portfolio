# Этап 3: приёмка применения и отката

Тестируйте на отдельной Windows 10 и Windows 11 VM, не на единственном рабочем ПК. Сначала сделайте снимок VM и системную точку восстановления; журнал приложения не заменяет внешнюю резервную копию.

## Запуск и новые файлы

Команда запуска из корня проекта: `.\.venv\Scripts\python.exe -m app.main`. Основные новые файлы: `catalog.py`, `backup_store.py`, `tweaks.py`, `windows_backend.py`, `tests/test_tweaks.py`, `tools/audit_windows.py`; изменённые UI-модули перечислены в README.

## Базовая проверка

- [ ] Запуск без UAC; отсутствуют сеть, автозапуск, скрытые процессы и автоматическая перезагрузка.
- [ ] В каждой из пяти групп есть доступный твик, описание, риск, `i`, переключатель и «В набор».
- [ ] По `i` показаны реальные пути/тип, текущее значение, исходное из журнала при его наличии и целевое значение.
- [ ] При отказе в подтверждении системная запись не выполняется.
- [ ] Применить один твик: его исходные значения записаны в `%APPDATA%/ShatliFlux/backup.json`.
- [ ] Значения в Windows совпадают с целевыми; после необходимого перезапуска проверить эффект через системные настройки.
- [ ] Откатить твик: значения и их типы точно совпадают с исходными.
- [ ] Выполнить те же проверки для каждого доступного твика отдельно.
- [ ] Для плана питания сравнивать GUID, не только локализованное название.
- [ ] После отсутствовавшего значения откат удаляет его, не создаёт «значение по умолчанию».
- [ ] На машине без стандартной схемы высокой производительности она не создаётся.

## Набор, группы и журнал

- [ ] Выбрать несколько «В набор», открыть главную, проверить знаменатель кольца.
- [ ] После применения числитель совпадает с числом выбранных записей `applied`.
- [ ] Применённый вне набора твик не увеличивает числитель выбранного набора.
- [ ] Применение/откат группы затрагивает только реализованные пункты группы.
- [ ] Перезапустить приложение: статусы из backup.json восстановлены; выбор «В набор» сброшен по текущей спецификации.
- [ ] Повторное применение не заменяет первое исходное значение.
- [ ] «Откатить всё» работает без Telegram, подписки и интернета.
- [ ] В «Безопасности» видны исходные и новые значения, события и состояние частичного отката.

## Сбои и конфликты: только на VM

- [ ] Сделать каталог журнала недоступным для записи, применить твик: реестр не изменён.
- [ ] Прервать тестовую операцию между записью значения и отметкой успеха: после запуска доступен откат по промежуточной записи.
- [ ] Сбой на втором изменении многошагового твика не удаляет исходные данные первого.
- [ ] После применения вручную изменить один параметр: откат не перезаписывает обнаруженное внешнее значение, но восстанавливает неконфликтующие пункты.
- [ ] После частичного отката проверить состояние каждого параметра, не только общий текст.
- [ ] Повторный откат уже откатанного пункта не меняет новую ручную настройку.
- [ ] Два экземпляра не выполняют изменения одного журнала одновременно.
- [ ] Повреждённый JSON не заменяется пустым файлом.
- [ ] Копия от другого пользователя или компьютера отклоняется.
- [ ] После ошибки или отмены переключатель не показывает неподтверждённое применение.

Тесты аварий нельзя проводить путём произвольного удаления единственной резервной копии. Храните внешний снимок VM и копию исходного `backup.json`; отсутствие самого файла после пользовательского удаления нельзя автоматически восстановить.

## Автоматические тесты

`python -m pytest -q` проверяет ядро на подставном хранилище и интерфейс на Qt offscreen. Это позволяет проверить порядок записи и сценарии сбоя без изменения настоящего реестра, но не доказывает поддержку конкретной сборки Windows.

Инструмент `tools/audit_windows.py` предназначен для чтения и сравнения настоящих значений до и после ручного цикла apply/revert. Команды приведены в README; при ошибке чтения он не объявляет сравнение успешным.
