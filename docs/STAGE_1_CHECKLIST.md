# Проверка этапа 1

Это исторический чек-лист версии 0.1.0. Для текущей 0.4.0 используйте `STAGE_2.md`, `STAGE_3_CHECKLIST.md` и `STAGE_4_CHECKLIST.md`: в новой версии есть системные операции и интеграция подписки, Inter заменён на Alegreya.

Выполняйте приёмку из обычной учётной записи Windows 10 и отдельно Windows 11. Системные изменения этой версией не предусмотрены; полноценные тесты восстановления и реестра относятся к следующим этапам.

## Запуск и окно

- [ ] Полностью распаковать архив; выполнить команды из README на Python 3.12 x64.
- [ ] При запуске нет запроса UAC и окна PowerShell, созданного самим приложением. Если приложение запущено из терминала, исходный терминал остаётся открытым.
- [ ] Размер при запуске 1100×720 логических пикселей, минимум 960×640.
- [ ] Перетаскивание за шапку и надпись Shatli FLUX работает.
- [ ] Сворачивание и восстановление с панели задач работают; закрытие завершает приложение.
- [ ] Изменение размера за края и нижний правый угол работает; интерфейс не уходит за минимальный размер.
- [ ] Проверить масштабы Windows 100%, 125%, 150% и перенос между мониторами.
- [ ] На экране хватает места для минимального размера с учётом масштабирования. Внешний монитор или меньшее масштабирование нужны, если доступная область меньше минимума из ТЗ.

## Внешний вид

- [ ] Используется сплошной чёрный фон без изображения, размытия и движения; акценты синие.
- [ ] Текст в карточках резкий, границы и состояния кнопок различимы.
- [ ] Muli/Mulish отображают кириллицу, кнопки не обрезаются.
- [ ] На 1100×720 главная читается; на 960×640 всё доступно вертикальной прокруткой.
- [ ] Быстрые переключения разделов не оставляют пустую страницу после анимации.
- [ ] Левое меню помещается при минимальном размере, «FPS-тест» является отдельной страницей.

## Навигация и честные состояния

- [ ] Все десять разделов открываются мышью, активен ровно один.
- [ ] Ctrl+1…Ctrl+9 и Ctrl+0 переключают разделы, Tab/Shift+Tab перемещают фокус.
- [ ] «FPS-тест» содержит понятные шаги и не заявляет выдуманные результаты.
- [ ] Ни на одной странице нет обещаний прироста FPS или вымышленных данных ПК.
- [ ] Кнопки будущих функций недоступны и поясняют соответствующий этап.
- [ ] Автозапуск не отмечен, его нельзя включить на этапе 1.
- [ ] Щит в шапке и кнопка в профиле открывают одно окно «Безопасность».
- [ ] В безопасности нет фиктивного хеша, успешной проверки подписи или журнала изменений.
- [ ] Escape закрывает окно безопасности; основной интерфейс остаётся доступным.

## Отсутствие побочных эффектов

- [ ] При обычном запуске появился `%APPDATA%/ShatliFlux/log.txt`.
- [ ] В каталоге данных не появился `backup.json`, в автозагрузке нет новой записи.
- [ ] Нет запросов авторизации, оплаты и системных изменений.
- [ ] После отключения интернета интерфейс продолжает открываться и переключать вкладки.
- [ ] После закрытия не остаётся отдельного фонового процесса приложения.
- [ ] Отсутствующий шрифт приводит к понятному сообщению, а не к успешному запуску пустого окна.

## Автоматические тесты

Команды установки и запуска находятся в README. Тесты проверяют геометрию, переходы, минимальный размер, отсутствие доступных системных действий, поведение анимации, конфигурацию и структуру импортов.

Статическая проверка импортов не заменяет аудит безопасности или наблюдение за системой. Offscreen-тестирование не доказывает работоспособность нативного перетаскивания, DPI, UAC и панели задач в Windows.
