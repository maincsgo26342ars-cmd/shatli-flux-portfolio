# Приёмка клиента и внешней интеграции

Реализация Telegram-бота находится вне этого проекта. Этот список относится к клиенту
и API; внешние сценарии проверяются совместно после согласования протокола.

- [ ] Открытие клиента без UAC; FREE и откат доступны без оплаты.
- [ ] Согласованы API URL, ссылка входа и протокол отдельного проекта.
- [ ] Вход подтверждается владельцем Telegram-аккаунта, сессия одноразовая и ограничена по времени.
- [ ] Токен хранится через DPAPI; выход не удаляет резервную копию.
- [ ] Один активный ПК; повторный вход на нём не расходует лимит отвязок.
- [ ] Второй ПК не входит до отвязки первого; чужие устройства защищены.
- [ ] PRO подтверждается сервером; внешний сервис корректно передаёт оплату и возврат.
- [ ] Повторное событие платежа не начисляет доступ повторно.
- [ ] Сбой внешнего сервиса не уничтожает данные отката.
- [ ] Публичный HTTPS, защищённый служебный секрет и резервирование БД API настроены.
- [ ] Сборка не содержит серверной конфигурации, токенов или кода внешнего проекта.
