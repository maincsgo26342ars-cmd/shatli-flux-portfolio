# Shatli FLUX

Windows-приложение на **Python / PySide6** для управления настройками Windows и CS2, диагностики и сравнения производительности до и после изменений.

Публичная версия для технического знакомства с проектом: исходники клиента, reference API, тесты и инструменты сборки. Проект находится в разработке; публичный сервис авторизации и коммерческий релиз пока не развёрнуты.

## Возможности

- 23 настройки Windows и CS2, готовые пресеты и пользовательский набор.
- Сохранение исходного состояния перед изменениями и локальный откат.
- Обнаружение конфликтов при восстановлении, сохранение сторонних команд autoexec.cfg.
- Диагностика оборудования, системный замер и FPS-тест через PresentMon.
- История замеров, сравнение ДО/ПОСЛЕ и экспорт HTML-отчёта.
- Поиск Steam/CS2, настройки интерфейса и автозапуск по согласию пользователя.
- Клиент Telegram-авторизации, Windows DPAPI для токена и серверная проверка прав.
- Проверка подписанных Ed25519 документов обновлений.

Фиксированный прирост FPS не обещается: эффект зависит от системы и условий измерения. Привилегированные операции запрашивают UAC отдельно.

## Стек и архитектура

| Каталог | Назначение |
|---|---|
| `app/ui/` | PySide6-интерфейс, страницы, фоновые задачи |
| `app/core/` | Настройки, применение и откат, диагностика, замеры, авторизация |
| `app/core/scripts/` | PowerShell-адаптеры Windows и сбор метрик |
| `shared/` | HTTP-клиент и проверка разрешённых сетевых адресов |
| `server/` | FastAPI reference backend с SQLite, токенами и учётом доступа |
| `tests/` | Проверки логики, UI, системных адаптеров и API |
| `packaging/` | PyInstaller и Inno Setup |
| `tools/` | Подготовка ресурсов, профилирование, проверки и подписание |

Системные операции отделены от UI и тестируются через подставные адаптеры. Длительные задачи выполняются вне GUI-потока. Диагностика загружается по запросу, декоративные фоновые анимации отключены.

## Запуск

Windows 10/11, Python 3.12 x64:

```powershell
git clone https://github.com/maincsgo26342ars-cmd/shatli-flux-portfolio.git
cd shatli-flux-portfolio
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m app.main
```

Интерфейс, локальная диагностика и бесплатные функции доступны без Telegram-бота. В конфигурации API указан локальный адрес разработки. Для входа и PRO нужен настроенный backend. Telegram-бот ведётся в отдельном проекте и сюда не включён.

Для оценки кода не нужно применять настройки к основной системе. Реальные изменения и откат проверяйте на тестовой Windows-машине.

## Тесты и сборка

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m PyInstaller --clean -y packaging/ShatliFlux.spec
```

**Проверка публичной копии: 238 тестов прошли (19 ноября 2026).**

Тесты используют временные файлы и базы, подставные системные адаптеры и тестовые платёжные события. Они не заменяют ручную приёмку всех настроек на Windows 10/11. EXE появится после локальной сборки; готовый бинарный релиз здесь пока не опубликован.
